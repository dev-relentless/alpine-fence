# SPX Construction — brand assets

Drop production brand assets in this folder. The site auto-references them by these filenames:

| File                   | Purpose                   | Notes             |
| ---------------------- | ------------------------- | ----------------- |
| `logo.svg`             | Primary mark              | Used in header    |
| `logo-light.svg`       | Inverted mark             | Dark surfaces     |
| `favicon.ico`          | Browser favicon           | 32x32 minimum     |
| `apple-touch-icon.png` | iOS home-screen icon      | 180x180           |
| `icon-192.png`         | PWA icon                  | 192x192           |
| `icon-512.png`         | PWA icon                  | 512x512           |
| `og.jpg`               | Open Graph / social share | 1200x630          |

Project photography goes in `public/spx/projects/`.
