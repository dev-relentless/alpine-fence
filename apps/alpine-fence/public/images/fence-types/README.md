Drop one hero photo per fence type here. Recommended **1600 × 1200 (4:3)**, JPG, optimized < 350 KB.

Required filenames (referenced by `src/data/fenceTypes.ts`):

- `wood-fencing.jpg`
- `composite-fencing.jpg`
- `vinyl-fencing.jpg`
- `simtek-fence.jpg`
- `iron-fencing.jpg`
- `aluminum-fencing.jpg`
- `ranch-rail.jpg`
- `decking.jpg`
- `iron-railing.jpg`
- `vinyl-railing.jpg`
- `other.jpg`

Until a real photo is in place the grid will show a graceful tinted placeholder tile.
