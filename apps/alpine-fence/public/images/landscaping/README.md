# Yard & Landscape Image Assets

Kept separate from `/images/services/` and `/images/gallery/` so the
landscape division is cleanly carve-out-ready (Phase 4).

## Phase 1 Status

The site references `landscaping-hero-bg.jpg` from the pillar page.
Until a real photo is supplied, the page will render with a broken hero
background. Drop the file at `hero/landscaping-hero-bg.jpg` to activate.

For Phase 1 launch, a single hero shot is sufficient. Service-card and
gallery imagery is Phase 2 work (after 5–10 real jobs are completed and
photographed).

## Photo Brief (when commissioning a photographer)

- **Hero shot:** wide Utah backyard featuring sod + a retaining wall +
  a fence visible in frame. Late golden-hour light. Wasatch Mountains
  in background if possible.
- **Service shots:** one finished example per service. Clean, finished
  state — not in-progress. People optional but nice.
- **Gallery:** before/after pairs are gold. Same crew, same yard,
  same camera angle.
