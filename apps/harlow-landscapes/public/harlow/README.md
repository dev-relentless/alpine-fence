# Harlow Landscapes — brand assets

Drop production brand assets in this folder. The site auto-references them by these filenames:

| File                  | Purpose                              | Notes                          |
| --------------------- | ------------------------------------ | ------------------------------ |
| `logo.svg`            | Primary mark (dark on light)         | Used in header on light pages  |
| `logo-light.svg`      | Inverted mark (light on dark)        | Used on dark hero / footer     |
| `wordmark.svg`        | Wordmark only                        | Optional                       |
| `monogram.svg`        | H·L monogram                         | Optional                       |
| `favicon.ico`         | Browser favicon                      | 32x32 minimum                  |
| `apple-touch-icon.png`| iOS home-screen icon                 | 180x180                        |
| `icon-192.png`        | PWA icon                             | 192x192                        |
| `icon-512.png`        | PWA icon                             | 512x512                        |
| `og.jpg`              | Open Graph / social share            | 1200x630                       |

Project photography goes in `public/harlow/projects/<project-slug>.jpg`.
